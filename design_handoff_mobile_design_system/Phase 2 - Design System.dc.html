One system, mobile-first

Same visual identity — every color below already exists in styles.css today. The change is that each one now has a name, a role, and exactly one place it's defined. Ships as CSS custom properties + classes in the existing stylesheet; no new dependencies, no font payload.

A — Color

28 raw values → 24 semantic tokens

The four orphan "border" hexes and the four position text colors turned out to be the missing steps of four ramps. Naming them costs zero visual change: every hex below is already in the codebase. Each role gets four steps — tint (fill), line (border), base, soft (text on tint).

Mobile invariants. ① 44px minimum target, 8px minimum gap between adjacent targets. ② 16px minimum on form controls. ③ viewport-fit=cover + env(safe-area-inset-*) on the tab bar and every sheet. ④ Primary navigation and destructive actions live in the bottom third. ⑤ No horizontal scroll anywhere — ever. ⑥ CSS inverts to mobile-first: base rules are the phone, one @media (min-width: 760px) block adds the desktop layer, replacing the current 760/800 pair.
